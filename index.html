打开在线课表 ↗
它是什么

这是一个单文件网页课表（手机/电脑浏览器直接打开，零外部依赖）。数据存在你本机浏览器，云端只托管一份用于桌面小组件同步。

  • 在线链接（独立、不挑 WiFi、不依赖电脑开机）：https://minidith.github.io/kebiao/
  • iPhone 桌面小组件：用免费 Scriptable App 读云端 JSON，不点进 App 也能看课。
  • GitHub Action：每次同步自动校验课表数据，防止写错。
底部三个标签
  • 课表：按日 / 周查看，点格子调课、停课、加课。
  • 课程：本学期全部课程清单，可编辑、删除、加新课。
  • 管理：学期设置、导入 Excel、备份、生成小组件数据、一键同步。
一、看课表（课表页）
  • 右上角 日 / 周 切换：日＝当天课程，周＝周一到周日 × 第 1–12 节固定网格。
  • ‹ › 切上 / 下周；本周 一键回到当前教学周。
  • 日视图顶部 7 天日期条，点某天跳到那天。
  • 点课程格子 → 弹出：本周停课（假期 / 出差）、调课（改到某周几某节）、加一次临时课。
  • 页内「本周停课」按钮可一键停掉整周，再点恢复；所有操作都能撤销。
二、改课表

① 换学期整体导入：管理 → 导入 Excel 课表（.xlsx）。支持「新建学期」或「覆盖当前学期」。表格格式：首行星期，首列含「第 N 节」+ 时间，单元格含 课名【教师】(地点,第 X-Y 周)。

② 临时调 / 停 / 加：课表页直接点格子。

③ 大改某门课：课程页编辑 / 删除，或底部「+ 添加课程」。

④ 改学期信息：管理 → 修改学期设置（名称、第一周周一日期、总周数）。每学期间起始日不同就在这里设。

三、备份与防丢

数据只存在本机浏览器，清缓存 / 换手机会丢。务必：管理 → 导出备份（JSON） 存一份；需要时 导入备份（JSON） 恢复。

四、桌面小组件一键同步
1

管理 → GitHub 同步，填一次 PAT 令牌（仅 repo 权限，只存你手机浏览器）→ 保存设置。

2

改完课表，点 🚀 发布到 GitHub（一键同步）。

3

约 30 秒后桌面小组件自动刷新（GitHub Action 自动校验 + Pages 自动上线）。

提示：页面按钮用的 PAT 是 7 天有效期，到期后在 GitHub 重新生成一个同权限的填进「保存设置」即可；公网链接不受影响。

五、iPhone 桌面小组件安装
1

App Store 装 Scriptable（免费）。

2

打开 → 右上角 + → 全选粘贴 课表小组件.js → 命名「课表」。

3

桌面长按空白处 → 加小组件 → 选 Scriptable → 选尺寸（小 / 中 / 大）→ 长按组件 → 编辑 → Script 选「课表」。

小＝按当前时间显示「上午 / 下午 / 晚上 / 明天上午」的课。时段划分：8:00–11:30 为上午，13:40–17:10 为下午，18:00 以后为晚上；某时段的课全部结束后自动切到下一时段，晚上结束后显示次日上午。

中＝今天全部课程（含时间、课名、教师/地点），并标出当前所在时段，比小尺寸更全。

大＝当前教学周的网格视图（周一到周日 × 第 1–12 节，当日所在列高亮）。

脚本默认读云端 JSON，离线时回退读 Scriptable 文件夹里的同名文件。

六、首次添加到主屏幕（iPhone）

Safari 打开 https://minidith.github.io/kebiao/ → 分享 → 添加到主屏幕 → 桌面出现课表图标，离线也能开。

隐私提醒

在线链接是公开的，任何拿到地址的人都能看课表（一般无碍）。若介意，可后续换私有托管。GitHub 令牌只存在本机浏览器，不会上传到代码仓库。
